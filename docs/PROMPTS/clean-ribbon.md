# Промт: Чистка ribbon по канону

**Когда использовать:** когда ribbon расходится с `CANON_FEATURES.md`.
Копируется как задача для ассистента.

---

## Текст промта

Задача: **привести ribbon в соответствие с каноном.**

Источники правды:
- `docs/CANON_FEATURES.md` — что должно быть.
- `docs/BUTTONS_INVENTORY.md` — поштучный перечень кнопок со статусами.
- `docs/UI_ISSUES.md` — конкретные визуальные баги.

### Что делаем (по приоритету)

**P0 — быстрые фиксы:**
1. UI-003: локализовать `tool.project.loop`.
2. UI-016: добавить кнопку 🧩 Модули (disabled) в QAT.

**P1 — структурные:**
3. UI-004: Фаска и Оболочка → из больших в малые.
4. UI-005: Пересечение / Объединить / Вычесть → вынести в группу Boolean.
5. UI-006: Отверстие и Резьба → из «Создать» в «Изменить».
6. UI-007: добавить группы «Диагностика» и «Стандартные изделия».
7. UI-009: Эскиз / Выход — убрать «Очистить», добавить «Показать формат ▼».
8. UI-011: Вид / Навигация — убрать «Исходный вид».
9. UI-012: Вид / Виды — добавить Слева / Снизу / Сзади.
10. UI-015: QAT — переделать Меню и Создать ▼.
11. UI-002: малые кнопки — увеличить с 24 до 32 px.

**P2 — отложенные:**
12. UI-008: Проецирование → одна кнопка ▼ с 5 подпунктами.
13. UI-010: Эскиз — добавить группы Размеры и Вставка.
14. UI-013: Вид — добавить Стиль отображения и Фон.
15. UI-014: Сборка — Копировать / Зависимость / Свобода / BOM.

### Порядок

Один фикс = один коммит. После каждого:
1. Сборка: `ninja`.
2. Запуск: `./run.sh`.
3. Скрин вкладки.
4. Коммит: `fix(ui): <что>`.

### Правила

- **Сверяться с CANON_FEATURES перед каждым фиксом.**
- **Никаких самовольных кнопок** — если нет в каноне, не добавлять.
- **Обновлять BUTTONS_INVENTORY** — статус `❌` → `⚠️` → `✅`.
- **Обновлять UI_ISSUES** — перенести в «Закрытые» с коммитом.
- **Топология — святое.** Не обрезать, не мельчить.

### Критерий готовности

- Все P0 и P1 закрыты.
- Ribbon визуально совпадает с CANON_FEATURES.
- BUTTONS_INVENTORY: статусы актуальны.
- UI_ISSUES: открытых P0/P1 нет.

### Чего не делать

- Не менять структуру кнопок, если канон подтверждает текущее.
- Не «улучшать» канон по ходу — сначала обсудить с MikeVerx.
- Не делать рефакторинг Application.cpp в рамках этой задачи (это
  отдельная Фаза 1.5).

## Пошаговый пример

**Фикс UI-004 (Фаска большая → малая):**

1. Открыть `DrawRibbonModelTab` в `Application.cpp`.
2. Найти `RibbonSingleButton("fillet", ..., true)` — последний аргумент
   `true` = big.
3. Заменить на `false`.
4. Проверить сборку.
5. Скрин 3D-модели.
6. Коммит: `fix(ui): fillet and shell buttons small in Изменить`.
7. Обновить BUTTONS_INVENTORY, UI_ISSUES.

**Фикс UI-005 (Boolean в свою группу):**

1. Найти группу «Изменить» в `DrawRibbonModelTab`.
2. Убрать 3 кнопки: union / cut / intersect.
3. Создать новую группу `RibbonGroupStart()` + 3 кнопки + `RibbonGroupEnd("Boolean")`.
4. Проверить, что влезает (горизонтальный скролл если нет).
5. Скрин.
6. Коммит.
