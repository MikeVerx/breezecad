# BreezeCAD — Roadmap

План разработки и наполнения функционала. Обновляется по ходу работы.
Связанные документы: `PROJECT_STATE.md`, `TECH_DEBT.md`, `UI_LAYOUT.md`, `ADR/`.

**Дата создания:** 2026-09-21
**Текущая версия:** 0.1.x
**Статус:** Фаза 0 — проектирование UI

---

## Общая цель

Облегчённый кросс-платформенный САПР уровня Inventor / КОМПАС-3D.
Полноценное параметрическое моделирование, эскизы, сборки, стандартные изделия,
чертежи. Работает на слабом железе, ARM (Android-планшеты), Mac.

**Целевой вес:** 200-500 МБ. **Старт:** < 1 сек.
См. `ADR/0001-kernel-strategy.md` и `PROJECT_STATE.md`.

## Референсы из Inventor 2024

Собраны скрины UI Inventor для вдохновения и сверки. Полный индекс — в
`docs/UI_LAYOUT.md`. Ключевые:

- 3D-модель: 9 кнопок в Создать, 5 в Изменить, 3 в Массив, 3 в Рабочие элементы
- Эскиз: 7 в Создать (с подменю), 3 в Массив, 4 в Изменить, 5+ в Ограничения
- Отверстие / Сопряжение / Оболочка: с выпадающими меню
- Проецирование геометрии: 5 подпунктов
- Текст: обычный + по линии, диалог редактирования текста
- ViewCube: грани + рёбра + углы, стрелки вращения
- Боковая навигация: суперштурвал, зум, орбита, стиль отображения

## Соглашения о работе

1. **UI-first.** Сначала все кнопки/панели (заглушки), потом наполнение.
2. **Один этап за сессию.** Не пытаться сделать всё сразу.
3. **Только консольные команды.** Никаких «открой редактор».
4. **После каждой правки — сборка.** Если упало — `git checkout`.
5. **Коммит после каждой рабочей порции.**
6. **Обновление документации** — по мере изменений.
7. **Тесты перед коммитом.** Хотя бы запуск приложения.

См. подробные соглашения в `PROJECT_STATE.md`.
