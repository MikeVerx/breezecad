## 2. Что за проект

**BreezeCAD** — кросс-платформенный САПР. Цель: облегчённый Inventor /
КОМПАС-3D, который работает на слабом железе (4 ГБ ОЗУ, слабый iGPU),
на ARM (Android-планшеты), на Mac. Целевой вес сборки 200–500 МБ.
Целевой старт < 1 сек на среднем железе.

**Что НЕ делаем:** FEA/CFD, CAM, BIM, облако, обратный инжиниринг,
generative design, синхронное моделирование, IGES, импорт .ipt/.sldprt.

**Философия:** уважение ко времени пользователя. Автосохранения,
восстановление после крашей, никакой телеметрии, один язык — русский.

**Правило архитектуры:** код должен быть приятным для чужого программиста.
Опытный C++-разработчик должен понять проект за 5 минут.

## 5. Среда разработки

- ОС: Windows 11 (24H2+), MSYS2 MINGW64.
- Путь: `~/BreezeCAD` (в MSYS2: `/home/Мишаня/BreezeCAD`).
- Сборка: CMake + Ninja, папка `build/`.
- Запуск: `~/BreezeCAD/run.sh`.
- Компилятор: g++ 16.2.0 из MSYS2.
- OCCT: `~/occt/install/`.
- lunasvg: `~/lunasvg/install/`.
- gdb: `mingw-w64-x86_64-gdb`.
- objdump: работает (вывод через `LC_ALL=C`).

**Проверка чувствительных мест:**

- `file <filename>` — line endings (CRLF или LF).
- `LC_ALL=C objdump -p exe | tr -d '\0' | grep -aE 'DLL Name:' | awk '{print $3}'` — DLL.
- `tasklist | grep -i breezecad` — висящие процессы.
- `BREEZECAD_TRACE=1 ./breezecad.exe` — TRACE-лог.

4. После отмашки — открывай нужный файл/раздел, предлагай план, действуй
