## Фаза 1 — Скелет UI

**Период:** 2026-09-22 — 2026-09-23
**Статус:** ✅ ЗАКРЫТА (частично, см. UI_ISSUES)

### Что сделано

**QAT:**
- Лого BreezeCAD + микро-меню.
- Кнопка Документ (Backstage).
- Убраны: Создать ▼, Меню (лого-бриз), Проекты, Клетчатый шарик.
- Добавлены: Модули, Формат, Текстуры, Параметры, Измерение.
- Поиск + телеметрия справа.

**Ribbon — 6 вкладок -> 4:**
- 3D-модель / Эскиз / Сборка / Вид.
- Заглушка DrawRibbonAssemblyTab.

**RibbonButton:**
- bigW: 100 -> 108 -> 88 px.
- Иконка 32 px, текст в одну строку, fallback на уменьшенный шрифт.
- Без обрезки с `..` (не поддерживается шрифтом).
- Стрелка ▼ — вертикальная полоса справа.

**RibbonGroup:**
- Бледный фон группы + заголовок снизу по центру + разделитель.
- Member-переменная `myRibbonGroupStartY` для выравнивания (вместо static).

**Высоты ribbon:**
- Окно 195 -> 190 px.
- Child авто + горизонтальный скролл.
- Все группы одной высоты.

**Статус-бар:**
- Слева: режим / X:Y:Z / снап.
- Справа: 1:1 | Готово.
- Не уходит под правую панель.

**Home Screen / Backstage:**
- Левая колонка команд (Создать / Открыть / Сохранить / Экспорт /
  Управление / Свойства / Печать / Закрыть).
- Правая область: Последние документы + сортировка + карточки.
- Верх: BreezeCAD + Назад в документ + поиск + телеметрия.

**Темы:**
- 4 -> 3: Светлая / Тёмная / Авто.
- DeepSColor удалена, стала основной Тёмной.
- ApplyTheme упрощён.

**Иконка приложения:**
- `tools/svg2ico.cpp` — конвертер SVG -> ICO на lunasvg.
- `assets/icons/app.ico` — 6 размеров (16, 24, 32, 48, 64, 128).
- `resources/app.rc` + CMake WIN32.
- Иконка в заголовке окна и в exe.

**CAD-иконки (21 штука):**
- `assets/icons/cad/`: extrude, revolve, sweep, loft, hole, thread,
  fillet, chamfer, shell, union, cut, intersect, plane, axis, point,
  pattern_rect, pattern_circ, view_iso, view_top, view_front, view_right,
  parallel.
- Стиль Lucide (viewBox 24x24, stroke 2, currentColor).
- `IconsFontAwesome.h` — заменены ICON_* на cad/... где применимо.
- `IconManager` — предзагрузка всех cad-иконок.

**Оси X/Y/Z в дереве:**
- CreateBaseGeometry: теги 5, 6, 7.
- Рёбра 200 мм (-100..+100), двунаправленные.
- FT_Axis показывается в дереве.

**Локализация:**
- ~80 новых ключей.
- `tab.assembly` -> «Сборка».
- Короткие подписи для ribbon (Прямоугольник, Окружность, Сместить...).

**Backstage / footer:**
- Правая панель: хлястик 16x40 px, виден всегда.
- Footer «1:1 | Готово» не уходит под панель.

## Канон — утверждён 2026-09-23

**Коммит:** `745a60a`

Утверждены документы:
- CANON_FEATURES — что должно быть.
- BUTTONS_INVENTORY — поштучный перечень кнопок.
- FILE_FORMAT — структура .bzc.
- ARCHITECTURE — слои, ядро, UI.
- RULES — 38 правил работы.
- HANDOFF — инструкция для нового чата.
- METHODS — что работает, что нет.

**Ключевые решения канона:**
- Формат `.bzc` — ZIP + manifest + history.bin + кэши.
- OCAF — только как мост для `.cbf`.
- Кэширование промежуточных состояний с момента .bzc.
- STL Viewer как отдельный workspace (только измерения).
- Автосохранения: 3 версии + atomic write.
- Плагины — Фаза 5+.
- Lucide — резать, оставить только используемые.
- Модули: черчение, OCAF, рендер — отдельно.
