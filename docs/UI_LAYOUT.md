# BreezeCAD — UI Layout

Полный дизайн интерфейса BreezeCAD. Единый источник правды.
При смене чата — этот файл скидывается первым вместе с `PROJECT_STATE.md`.

**Статус:** черновик, наполняется по мере сбора референсов из Inventor 2024.
**Дата начала:** 2026-09-21

---

## 1. Принципы

### 1.1. Философия дизайна

- Простой, не перегруженный интерфейс. Кнопки хорошо различимы,
  не сливаются друг с другом.
- Единая цветовая палитра. Акцентный цвет читается и не отвлекает
  от работы (голубой/бирюзовый в тёмной теме).
- Всё окрашивается от темы: ViewCube, стрелки, виджеты, иконки,
  подсветка, полупрозрачные плоскости. Никаких «отсебятин».
- Структура и логика — от Inventor. Удобство взаимодействия
  (клава-мышь) — от КОМПАС-3D.
- Окна операций — **плавающие**. Могут выходить за пределы главного
  окна, в т.ч. уезжать на второй монитор.

### 1.2. Что копируем из Inventor (паттерны, не копирайт)

- Ribbon-интерфейс: QAT сверху, tabs, groups, большие/малые кнопки.
- Панель свойств справа для большинства операций (не модальные окна).
- Дерево документа слева.
- Модальные окна — только для сложных операций (Лофт, Ребро жёсткости).
- ViewCube с кликабельными гранями/рёбрами/углами.
- 3-уровневые тултипы (название → кратко → «Как пользоваться»).
- Home Screen: левая колонка с кнопками + сетка недавних.

### 1.3. Что НЕ копируем (юридически опасно)

- Иконки Autodesk (используем Lucide, MIT).
- Логотип Inventor.
- Дословные тексты справки Autodesk.
- Точные hex-коды Inventor (берём похожие, но свои).
- Названия продуктов Autodesk в UI.

### 1.4. Что НЕ делаем вообще

- Вкладки: Аннотации, Проверка, Инструменты, Управление, Среды,
  Совместная работа, Fusion 360.
- Модули: генератор форм, поверхности, прокладка кабелей, анализ
  напряжений, листовой металл, преобразование в листовой металл.
- QAT: кнопки «Проекты», «Молния», «Клетчатый шарик», «Непонятный
  символ».

### 1.5. Топология — жёсткие правила

Кнопки должны влезать в отведённые панели. Никаких обрезаний.
Иконки — аккуратные, одного визуального веса, читаемые на фоне
любой темы. Правая панель не «жирная»: 40 px свёрнутая.
Хлястик свёрнутой правой панели виден. Проверка перед каждым
коммитом — по чеклисту (см. раздел 2.3).

### 2.3. Чеклист топологии (перед каждым коммитом UI)

- [ ] QAT укладывается в 32 px, ни одна иконка не обрезана
- [ ] Ribbon укладывается в 78 px, подписи групп не наезжают
- [ ] Левая панель: текст не обрезается, ширина регулируется
- [ ] Правая панель: 40 px в свёрнутом виде
- [ ] Хлястик свёрнутой правой панели виден и читается
- [ ] Правая панель не «жирнее» 40 px в свёрнутом виде
- [ ] Иконки одного визуального веса
- [ ] Иконки читаемы на фоне обеих тем (Light / Тёмная)
- [ ] Тултипы не перекрывают кнопку, к которой относятся
- [ ] Единый spacing-токен (4 / 8 / 12 px) во всех панелях

### 2.4. Стиль

- **Светлая тема** — нейтральный серо-белый (в стиле Inventor).
- **Тёмная тема** — глубокая тёмная с бирюзовым акцентом
  (была DeepSColor, переименована).
- **Иконки** — Lucide, цветные, зависят от темы.
- **Плоскости** — matte, без бликов, полупрозрачные.

## 3. QAT (Quick Access Toolbar)

Верхняя строка окна, **32 px**. Слева — функциональные кнопки, справа —
поиск команд и телеметрия. Логотип — первая слева, элемент брендинга.

### 3.1. Схема
+---------------------------------------------------------------------------------+
| [logo] [Doc] | [Save] [<-] [->] | [Home] | [Mod] [Fmt] [Tex] [fx] [Meas] | Poisk | FPS RAM |
+---------------------------------------------------------------------------------+
  brand  backstage  save   undo redo   home   moduli format tex   params measure

### 3.2. Кнопки слева-направо

| № | Иконка | Название | Действие | Выпадашка |
|---|--------|----------|----------|-----------|
| 1 | 🌀 `breeze-logo-small.svg` 24×24 | Брендинг | Микро-меню: О программе / Настройки / Справка | ▼ |
| 2 | 📄 | **Документ** | Открывает **Backstage** (файловый экран) | нет |
| — | │ разделитель | | | |
| 3 | 💾 | Сохранить | Быстрое сохранение текущего документа | нет |
| 4 | ← | Undo | Отменить | нет |
| 5 | → | Redo | Повторить | нет |
| — | │ разделитель | | | |
| 6 | 🏠 | Home | Возврат на главную | нет |
| — | │ разделитель | | | |
| 7 | 🧩 | **Модули** | Управление модулями (установка / удаление) | нет |
| 8 | ▦+▾ | Показать формат | Настройки отображения эскиза | ▼ чекбоксы: линии / размеры / ограничения |
| 9 | 🎨+▾ | Текстуры | Применить материал | ▼ палитра + «Импортировать текстуру» |
| 10 | fx | Параметры | Таблица параметров | нет |
| 11 | 📏+▾ | Измерение | Инструмент измерения | ▼ контекстное меню точности |

### 3.3. Правая зона

- 🔍 **Поиск команд** — поле ввода, 220 px. Живой поиск по всем командам
  приложения, открывает палитру результатов.
- 📊 **Телеметрия** — `FPS: 60 | RAM: 95 MB | Obj: 4`. Только чтение,
  компактный моноширинный шрифт.

### 3.4. Создание документов (внутри Backstage)

Отдельной кнопки «Создать» в QAT **нет**. Всё создание документов
происходит в **Backstage** (клик на 📄):

| Пункт | Статус |
|-------|--------|
| **Деталь** | активен (default) |
| **Сборка** | активен |
| **Черчение** | серым, при клике → диалог «Хотите установить модуль чертежей?» + кнопка «Отмена» |

См. раздел 17 «Backstage / Файл».

### 3.5. Убрано (по сравнению с предыдущей версией QAT)

- ❌ Кнопка «Создать ▼» — переехала в Backstage.
- ❌ Кнопка «Меню (лого-бриз)» — заменена на микро-меню у логотипа.
- ❌ Кнопка «Проекты» (молния) — не нужна.
- ❌ Кнопка «Клетчатый шарик» (проверка материала) — не нужна.
- ❌ Кнопка «Непонятный символ» (обновление) — не нужна.
- ⏸ Кнопка «Выбор / Selection Filter» — заложена в дизайн, но disabled
  (отложено на будущую итерацию).

### 3.6. Топология QAT

- Высота — **32 px**, фиксирована.
- Иконки — 20×20 px, выровнены по центру вертикали.
- Лого — 24×24 px (из `breeze-logo-small.svg`).
- Разделители — тонкая вертикальная линия, 1 px, цвет `ribbon_border`.
- Выпадашка `▾` — 8×8 px в правом нижнем углу иконки.
- Отступы между кнопками — 4 px, между группами (через разделитель) — 8 px.
- Кнопки НЕ обрезаются. Если не влезает — иконки уменьшаются до 18×18.

### 4.1. Плоскость (рабочий элемент)

Кнопка с выпадашкой в группе «Рабочие элементы».

#### 4.1.1. 13 вариантов (выпадашка)

Разделены на 4 блока.

Базовые:
1. Плоскость
2. Смещение относительно плоскости
3. Параллельно плоскости через точку
4. Средняя плоскость между двумя плоскостями
5. Симметрично тору
6. Угол к плоскости вокруг ребра

По геометрии:
7. Три точки
8. Два компланарных ребра

Касательные:
9. Касательная к поверхности через ребро
10. Касательная к поверхности через точку
11. Касательная к поверхности и параллельно плоскости

Перпендикулярные:
12. Перпендикулярно оси через точку
13. Перпендикулярно кривой в точке

#### 4.1.2. Инлайн-виджет вьюпорта

Для быстрых операций (смещение, угол) — плавающее поле ввода
прямо в 3D-вьюпорте, рядом с геометрией.

| Операция | Виджет | Кнопки |
|----------|--------|--------|
| Смещение относительно плоскости | 0.000 мм | OK / X / [v] |
| Угол к плоскости вокруг ребра | 90.00 град | OK / X / [v] |

Требования к виджету:

- Не закрывает линии модели.
- Не убегает от курсора при попытке его использовать.
- Работает вместе с панелью свойств, не вместо.
- Ввод значения — с клавиатуры или перетаскиванием.
- Реверс направления — минусом в поле.
- Может быть отключён в Настройках -> Управление.

#### 4.1.3. Стек опорных плоскостей

Плоскость создаётся относительно:

- Базовых плоскостей (XY / XZ / YZ).
- Граней модели.
- Ранее построенных рабочих плоскостей.
- Плоскостей на 2D-эскизе.

Цепочка наследования сохраняется в дереве документа.

#### 4.1.4. Выбор опорной геометрии

- Выбор в 3D-вьюпорте кликом.
- Выбор через дерево документа.
- Точки — контрастным цветом, грани и плоскости — цветом темы.
- Префильтра нет: при наведении показывается «предложение по выбору».

#### 4.1.5. Средняя плоскость — правила

- Две параллельные грани -> эквидистанта посередине.
- Две непараллельные грани -> биссектор (при 90 град встаёт под 45 град).

#### 4.1.6. Обработка ошибок выбора

- Невалидный выбор -> красная иконка + сообщение «Исправьте выбор».
- Кнопки: Изменить / Отмена.

### 4.3. Диалоги операций — единый стиль

Все окна операций — **плавающие**. Могут выходить за пределы
главного окна, уезжать на второй монитор. Перетаскиваются за
заголовок.

Три варианта UI для операций:

| Тип | Когда | Пример |
|-----|-------|--------|
| Инлайн-виджет во вьюпорте | Простые, параметр один | Смещение плоскости, Угол |
| Плавающее окно | Большинство, 3-10 параметров | Сопряжение, Массивы, Отверстие, Выдавливание |
| Плавающее окно, расширенное | Сложные операции с табами | Лофт, Ребро жёсткости, Редактирование текста |

**Структура плавающего окна (универсальная):**

- Заголовок: имя операции + пиктограмма глаза + «Последний использованный».
- Секция «Геометрия ввода»: что выделено (профили, оси, пути).
- Секция «Режим»: направление, расстояние/угол, ограничение.
- Секция «Вывод»: имя тела.
- Секция «Дополнительные свойства»: конус, конструктивная пара, продлённый контур.
- Кнопки внизу: OK / Отмена / [+] / [>>].

**Правая панель окна приложения** (не путать с диалогами) — это
навигация, дерево, свойства выделенного объекта, телеметрия.
Складывается ползунком до 40 px, разворачивается до 280 px.

### 4.5. Сопряжение

Три операции в группе «Изменить» ribbon:

| Кнопка | Тип | Форма |
|--------|-----|-------|
| Сопряжение ▼ | основная | плавающее окно, 3 типа наборов |
| Сопряжение грани | грань-грань | плавающее окно |
| Полное круговое сопряжение | по трём граням | плавающее окно |

#### 4.5.1. Диалог «Сопряжение»

Одна операция — три типа наборов. Смешивание наборов внутри одной
операции разрешено.

**Секция «Наборы объектов»** — список наборов. Правый вертикальный
тулбар:

| Кнопка | Действие |
|--------|----------|
| [+][R] | добавить набор с постоянным радиусом |
| [+][V] | добавить набор с переменным радиусом |
| [+][S] | добавить угловой отступ (setback) |
| [->]  | режим выбора рёбер |
| [X]   | удалить набор |

**Поля набора (зависят от типа):**

| Тип | Поля |
