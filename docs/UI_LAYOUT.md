# BreezeCAD — UI Layout

Полный дизайн интерфейса BreezeCAD. Единый источник правды.
При смене чата — этот файл скидывается первым вместе с `PROJECT_STATE.md`.

**Статус:** черновик, наполняется по мере сбора референсов из Inventor 2024.
**Дата начала:** 2026-09-21

---

## 1. Принципы

### Что копируем из Inventor (паттерны, не копирайт)

- Ribbon-интерфейс: QAT сверху, tabs, groups, большие/малые кнопки.
- Панель свойств справа для большинства операций (не модальные окна).
- Дерево документа слева.
- Модальные окна — только для сложных операций (Лофт, Ребро жёсткости).
- ViewCube с кликабельными гранями/рёбрами/углами.
- 3-уровневые тултипы (название → кратко → «Как пользоваться»).
- Home Screen: левая колонка с кнопками + сетка недавних.

### Что НЕ копируем (юридически опасно)

- Иконки Autodesk (используем Lucide, MIT).
- Логотип Inventor.
- Дословные тексты справки Autodesk.
- Точные hex-коды Inventor (берём похожие, но свои).
- Названия продуктов Autodesk в UI.

### Что НЕ делаем вообще

- Вкладки: Аннотации, Проверка, Инструменты, Управление, Среды, Совместная работа, Fusion 360.
- Модули: генератор форм, поверхности, прокладка кабелей, анализ напряжений,
  листовой металл, преобразование в листовой металл.
- QAT: кнопки «Проекты», «Молния», «Клетчатый шарик», «Непонятный символ».

## 2. Общая компоновка окна


**Размеры (ориентир):**
- QAT: 32 px высота.
- Tabs + Ribbon: 110 px суммарно (сейчас 195 — сжимаем).
- Левая панель: 280 px ширина (регулируется).
- Правая панель: 40 px свёрнутая, 280 px развёрнутая.
- Tab-бар проектов: 32 px.
- Статус-бар: 24 px.

**Стиль:**
- Светлая тема — в стиле Inventor (нейтральный серо-белый).
- Тёмная — DeepS (бирюзовый акцент).
- Иконки Lucide, цветные, зависят от темы.
- Плоскости — matte, без бликов, полупрозрачные.

### 4.1. Подменю «Плоскость» (13 вариантов)

Базовые:
1. Плоскость
2. Смещение относительно плоскости
3. Параллельно плоскости через точку
4. Средняя плоскость между двумя плоскостями
5. Симметрично тору
6. Угол к плоскости вокруг ребра

По геометрии:
7. Три точки
8. Два компланарных ребра

Касательные:
9. Касательная к поверхности через ребро
10. Касательная к поверхности через точку
11. Касательная к поверхности и параллельно плоскости

Перпендикулярные:
12. Перпендикулярно оси через точку
13. Перпендикулярно кривой в точке

### 4.2. Подменю «Отверстие» (8 типов)

**Тип «Отверстие» (4 варианта):**
1. Простое
2. С зенковкой (countersink)
3. С цековкой (counterbore)
4. С конической зенковкой

**Тип «Опора» (4 варианта):**
5. Без опоры
6. Цековка
7. Зенковка
8. Коническая зенковка

**Параметры отверстия:**
- Резьба: тип / размер / обозначение / класс / направление
- Крепёж (если применимо): стандарт / тип крепежа / размер / посадка
- Ограничение: до поверхности / насквозь / до плоскости
- Направление: прямо / обратно / симметрично

**Крепёж (отдельная группа параметров при типе «крепёж»):**
- Стандарт (ANSI / ISO / DIN / ГОСТ)
- Тип крепежа (винт крепежный с плоской, ...)
- Размер
- Посадка (переходная, с зазором, с натягом)

### 4.3. Диалоги операций

**Панель свойств справа** — формат по умолчанию для: Выдавливание, Вращение,
Сдвиг, Отверстие, Сопряжение, Фаска, Оболочка, Наклон, Пружина, Массив.

**Модальные окна** — для сложных: Лофт (3 таба: Кривые, Условия, Переход),
Ребро жёсткости (Форма, Уклон, Бобышка).

**Структура панели свойств (универсальная):**
- Заголовок: имя операции + пиктограмма глаза + кнопка «Последний использованный»
- Секция «Геометрия ввода»: что выделено (профили, оси, пути)
- Секция «Режим»: направление, расстояние/угол, ограничение
- Секция «Вывод»: имя тела
- Секция «Дополнительные свойства»: конус, конструктивная пара, продлённый контур
- Кнопки снизу: ОК / Отмена / + (создать и продолжить)

### 4.4. Специфичные панели

**Выдавливание:** направление (4), расстояние, конус, имя тела.
**Вращение:** ось, угол (по умолч. 360°), конус, имя тела.
**Сдвиг:** путь (кривая), ориентация (3 варианта), имя тела.
**Отверстие:** тип × 8, резьба, крепёж, ограничение, направление.
**Сопряжение:** наборы рёбер, радиус, панель справа с 3 типами.
**Пружина:** метод (шаг+число витков), шаг, число витков, конус, поворот,
поджатые витки, торцевой виток.
