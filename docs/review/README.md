# BreezeCAD — Code Review (индекс)

**Дата создания:** 2026-09-27
**Источник:** разбиение `docs/CODE_REVIEW.md` (архив: `docs/archive/CODE_REVIEW_v1.md`)

## Как пользоваться

1. Работай с файлами по приоритету: **P0 → P1 → P2 → P3**.
2. Каждая запись независима — содержит Где / Статус / Категория / Проблема / Фикс / Оценка.
3. После фикса: `Статус: OPEN` → `Статус: FIXED (коммит XXXX)` и запись переносится в `FIXED.md`.
4. Прогресс-таблица внизу обновляется по мере закрытия.

## Легенда приоритетов

- **P0 — критично:** нарушает правила проекта / философию / функционал. Фиксить сейчас.
- **P1 — серьёзно:** архитектура, производительность, RULES-нарушения. До Фазы 2.
- **P2 — стиль:** читаемость, magic numbers, консистентность.
- **P3 — мелочи:** некритичные замечания.
- **RAM — гипотезы:** отдельный фронт, диагностика + план.
