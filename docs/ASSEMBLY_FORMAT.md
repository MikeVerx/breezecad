# Файл сборки

Сборка — файл `.bza` (деталь — `.bzc`). Внутри тот же контейнер, что у детали
(ZIP: `manifest.json` + `document.json`). Вид документа определяется по полю
`documentType` манифеста, а не по расширению: переименованный файл всё равно
откроется правильно. Список видов и их расширения — `document/DocumentTypes.*`
(`part` .bzc, `assembly` .bza, `drawing` — пока заглушка). Файлы без
`documentType` считаются деталями. Значок файла в проводнике появится, когда
будет установщик с регистрацией расширений (сейчас программа их не регистрирует).

Компонент ссылается на файл детали путём относительно файла сборки
(разделитель `/`). Пока сборка не сохранена, путь абсолютный.

**Детали лежат вместе со сборкой** (с 0.2.3.2, `GatherParts`): при каждом
сохранении деталь, которая лежит не в папке сборки, копируется туда под именем
`<деталь> - <сборка>.bzc`, и компонент ссылается на копию. Так папку со сборкой
можно перенести на другой компьютер или телефон — она откроется со всеми
деталями. Подробности:

- Деталь, уже лежащая в папке сборки, не копируется. На ПК подпапки тоже считаются
  (`Стандартные изделия/`); на Android — только сама папка проектов (она плоская).
- Одинаковые компоненты получают одну копию. Если копия с таким же содержимым
  уже есть (`Вал - Узел.bzc`, `Вал - Узел (2).bzc`), она используется снова; файл
  с этим именем, но другим содержимым, не перезаписывается — берётся `(2)`, `(3)`…
- У сохранённой сборки деталь копируется сразу при вставке, у новой — при первом
  сохранении. «Сохранить как» в другую папку копирует детали туда
  (`Вал - Узел.bzc` → `Вал - Узел 2.bzc`, без двойного имени).
- Не найденная деталь не копируется: об этом сообщение, остальное сохраняется.
  Если копию сделать не удалось — сборка не сохраняется.
- Android: копии всех документов папки проектов лежат во внутренней папке
  программы рядом друг с другом, как в самой папке проектов, поэтому пути
  у сборки те же, что на ПК. При открытии сборки её детали заново берутся из
  папки проектов (они могли прийти с компьютера). Сборку с деталями на Android
  можно сохранить только в папку проектов.

```json
{
  "assembly": { "name": "Узел", "designation": "БРЗ.100.000" },
  "formatVersion": 1,
  "nextId": 4,
  "components": [
    { "id": 1, "name": "Основание:1", "path": "Детали/Основание.bzc",
      "placement": { "origin": [0,0,0], "xAxis": [1,0,0], "zAxis": [0,0,1] },
      "properties": { "designation": "", "name": "", "material": "", "quantity": 1 },
      "grounded": true }
  ],
  "constraints": [
    { "id": 3, "name": "Вставка:1", "type": "insert", "value": 0, "flipped": false,
      "first":  { "component": 1, "kind": "circle", "origin": [..], "direction": [..], "radius": 4, "pick": [..] },
      "second": { "component": 2, "kind": "circle", ... } }
  ]
}
```

- `placement` — оси детали в координатах сборки (как у рабочей плоскости), без углов Эйлера.
- `properties` — для будущей спецификации; пустое поле = взять из свойств детали.
- Типы зависимостей: `mate` (совмещение; `flipped` = заподлицо), `insert` (вставка;
  `flipped` = соосно в одну сторону), `angle` (`value` в радианах), `tangent`
  (`flipped` = внутреннее касание), `axisMate` (совпадение осей). `value` — зазор, мм.
- Соединения (подвижные): `jointRotational`, `jointSlider`, `jointCylindrical`,
  `jointPlanar`, `jointBall`, `jointRigid`. Геометрия задаёт систему координат: `origin`,
  Z = `direction`, X = `reference` (необязательно; нет — X строится из Z). `flipped` — оси Z
  в одну сторону (иначе навстречу), `value` — смещение вдоль оси, мм (вращение, плоское,
  жёсткое). Для вращения и ползуна: `locked` + `position` (рад / мм) — заблокировано в
  положении; `limits: {lower, upper}` — пределы. Все новые ключи необязательны, версия прежняя.
- Геометрия (`kind`: plane, axis, point, cylinder, sphere, circle) хранится в
  координатах детали; `pick` — точка щелчка, по ней геометрия ищется снова, когда
  деталь изменилась.
- Неизвестный тип зависимости пропускается с предупреждением; повреждённый компонент —
  ошибка открытия.

## Зависимости уровня Inventor (feat/assembly-design)

Все ключи ниже необязательны: файлы без них открываются как раньше, `formatVersion`
прежний. Старая программа пропустит незнакомые типы зависимостей с предупреждением.

- **Что выбрано** — у геометрии `from`: `face` (по умолчанию, ключ не пишется), `edge`
  (прямое ребро — линия, круглое — окружность), `vertex` (точка), `element` (начало
  координат или рабочая геометрия детали; `element` — её id в детали: 1 центр,
  2–4 плоскости XY/XZ/YZ, 5–7 оси X/Y/Z, иначе id рабочей плоскости/оси/точки).
  По `from` и `pick` геометрия находится снова, когда деталь изменилась.
- **Начало координат сборки** — `component: 18446744073709551615` (2⁶⁴−1, «компонент»
  неподвижного начала координат) с `from: element` и `element` 1–7.
- **Совмещение по любой паре** плоскость / линия / точка: `mate` с геометриями `kind`
  plane, axis или point (точка на линии, линия в плоскости, точка в точке и т. п.).
- **Симметрия** — `type: symmetry`, `first` и `second` — симметричные грани, оси или
  точки, `third` — плоскость симметрии; `flipped` — грани смотрят друг на друга.
- **Пределы** у `mate` и `angle` — тот же `limits: {lower, upper}` (мм / рад), что у
  соединений: зависимость держит значение в этих пределах, а не точное `value`.
- **Передачи** между соединениями (без `first`/`second`): `type: gear` — `drive` и
  `driven` — id двух `jointRotational`, `ratio` — оборотов ведомого на оборот ведущего,
  `flipped` — в разные стороны (внешнее зацепление); `type: screw` — `drive`
  вращение, `driven` — ползун, `ratio` — мм на оборот. `at: [ведущее, ведомое]` —
  координаты соединений, от которых передача отсчитывает (рад / мм). Удаление
  соединения удаляет и его передачу.

## Детали, спроектированные в сборке

- Деталь, правленная на месте или созданная в сборке, пишется при сохранении сборки
  в копию рядом с ней (`<деталь> - <сборка>.bzc`, правило выше); исходник не трогается.
- Проекции рёбер соседних деталей хранятся в эскизе детали (`document.json` детали):

```json
"contextProjections": [
  { "assembly": "Узел", "component": 1,
    "edge": { "curve": "circle", "middle": [45, 25, 10], "radius": 5, ... },
    "curve": 19 }
]
```

  `assembly` — имя сборки (связь действует, только когда деталь правится в ней),
  `component` — id компонента-источника в этой сборке, `edge` — его ребро в
  координатах его детали, `curve` — кривая эскиза; `adaptive: false` — связь
  отключена (кривая стоит на месте). Деталь, открытая сама по себе, просто
  показывает кривые там, где они были в последний раз.
