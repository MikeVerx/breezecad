# BreezeCAD 0.2.1-Beta

Первый номерной патч после 0.2.0: сборки, модули, три операционные системы и
большая работа над стабильностью.

## Новое

**Сборки (.bza)**
- Новый вид документа — сборка: вставка деталей (из файла и из библиотеки), перемещение и поворот компонентов.
- Зависимости (совмещение, вставка, угол, касание, совпадение осей) с решателем и степенями свободы в дереве.
- Подвижные соединения: вращение, ползун, цилиндрическое, плоское, шаровое, жёсткое — с положением, блокировкой и пределами.
- Массивы компонентов (по отверстиям, прямоугольный, круговой) и AutoDrop: винт подбирается по отверстию, длина — по пакету деталей.
- Проверка пересечений деталей с именами компонентов.

**Детали**
- Оболочка, рабочая точка, библиотека стандартных изделий (крепёж, подшипники, кольца, штифты, шплинты).
- Внешний вид: цвета и текстуры на тела и отдельные грани, размер и качество текстур; детали приносят свой вид в сборку.
- «Скрыть» отдельно от «Подавить» (глаз в дереве), фаска и скругление по целой грани, выдавливание до кривой грани.

**Программа**
- Модули: установка из пакета .bzmod кнопкой или перетаскиванием, вкл/выкл, отключение упавшего модуля; API команд для модулей.
- macOS (Apple Silicon, macOS 14+) и Linux — готовые сборки наравне с Windows.
- Жесты тачпада на всех системах (сдвиг, вращение, масштаб, поворот), своя вкладка настроек с картинками.
- Свободное вращение вида по умолчанию, «поворотный стол» — в настройках.
- Сборка для бета-тестеров: журнал сессии и «Сообщить о проблеме» одним архивом.
- Фоны вида, заставка при запуске, окно «О программе» с точной сборкой.

## Стабильность

- Сбой внутри геометрического ядра во время операции ломает только эту операцию, а не программу.
- Повреждённый или отредактированный вручную файл детали или сборки — сообщение «повреждён» вместо вылета.
- Испорченный `settings.json` больше не мешает запуску: настройки сбрасываются, старый файл сохраняется как `settings.json.bak`.
- Нет вылета, если открытый документ удалили или вынули флешку, а потом открыли другой файл.
- Огромное число в угловом размере больше не вешает программу; чудовищно длинное выражение в поле размера — сообщение вместо вылета.
- Недоступная папка автосохранений (антивирус, OneDrive) не мешает запуску.
- Оболочка, которую ядро на самом деле не построило, показывается как ошибка с подсказкой, а не как сплошная деталь.

## Известные проблемы

- «Вращение» по профилю из спроецированных граней (например, зеркальных тел) может закрыть программу — разбирается в первую очередь.
- Повреждённый эскиз с элементами без точек (B-02) при открытии может закрыть программу.
- Сборка для macOS без подписи Apple: первый запуск — правой кнопкой → «Открыть».
