## Как проверялось

1. **Чтение кода** — практически весь `src/` (≈42 700 строк), с мысленным
   прогоном сценариев: повреждённые файлы, отмена посреди инструмента, две
   вкладки, долгие операции, нехватка памяти, удалённые файлы.
2. **Исходники OCCT 7.8.1** — чтобы проверить, как наш перехват падений
   взаимодействует с механизмом ошибок ядра (B-07, B-08).
3. **Стенд** (`tests/audit/`): нижние слои (`core`, `sketch`, `document`)
   собраны с AddressSanitizer + UndefinedBehaviorSanitizer, каждый зонд — в
   отдельном процессе. Подтверждены B-01, B-02, B-03, B-10.
4. **Замеры** решателя эскиза в сборке `-O2` (O-01).
5. **Полная сборка и тесты** на Linux — результат в разделе «Прогон на Linux» ниже.

Обозначения уверенности: ✅ воспроизведено, 📖 механизм проверен по коду,
🔍 почти наверняка по коду, руками не воспроизводилось.
