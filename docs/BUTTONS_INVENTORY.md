# BreezeCAD — Полный перечень кнопок

**Назначение:** поштучный чек-лист всех кнопок с их статусом реализации.
Используется для отслеживания прогресса и сверки с `CANON_FEATURES.md`.

**Легенда статуса:**
- ✅ реализовано и работает
- 🔨 в работе
- ⚠️ частично (есть кнопка, нет функционала)
- ❌ не реализовано
- ⏸ отложено / disabled
- 🗑 лишнее, удалить

**Легенда размера:**
- **Б** = большая (~88×74)
- **С** = средняя (~44×44)
- **М** = малая (~32×32)
- **КМ** = кнопка-меню (большая + вертикальная полоса-стрелка справа)

**Дата:** 2026-09-23

## Приоритеты

### 🔴 P0 — для Фазы 1.5 (рефакторинг)
- Убрать лишние кнопки (🗑).
- Добавить отсутствующие заглушки.
- QAT — переделать «Меню» и «Создать ▼».

### 🟡 P1 — для Фазы 2 (функционал)
- Плавающие окна операций (Выдавливание, Вращение, Отверстие, Сопряжение).
- Инлайн-виджет вьюпорта.
- Панель свойств (левая, вкладка Параметры).
- ViewCube с рёбрами.

### 🟢 P2 — для Фазы 3+
- Эскизные размеры.
- Сборка целиком.
- Стандартные изделия.
- STL Viewer.
