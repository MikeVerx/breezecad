# Пакеты стандартных изделий (`*.bzlib`) — формат

Пакет — JSON-файл (UTF-8) с расширением `.bzlib`. В нём виды изделий (как
построить) и стандарты (таблицы размеров). Решение и его причины —
[ADR-0006](ADR/0006-standard-part-packs.md); пример — `assets/library/gost30245.bzlib`.

Установка: окно «Библиотека» → «Добавить пакет стандартных изделий», или
перетащить файл в окно программы, или команда `library.add_pack`. Файл
проверяется и копируется в `<папка настроек BreezeCAD>/library/`.

## Пакет

```json
{
  "format": "breezecad-standard-parts",
  "version": 1,
  "id": "gost30245",
  "title": "Профили гнутые замкнутые сварные",
  "source": "ГОСТ 30245-2003, таблицы 1 и 2",
  "author": "…",
  "version_of_data": "1",
  "kinds": [ … ],
  "standards": [ … ]
}
```

| Поле | Обязательно | Что это |
|---|---|---|
| `format` | да | всегда `breezecad-standard-parts` |
| `version` | да | версия формата, сейчас `1`; пакет новее программы не читается |
| `id` | да | латиница, цифры, `.`, `-`, `_`, до 64 знаков; имя файла при установке |
| `title` | да | название пакета |
| `source` | нет | **откуда цифры**: стандарт, таблица, примечание. Пишите всегда |
| `kinds` | нет | виды изделий (может не быть, если стандарты — для вида из другого пакета) |
| `standards` | да | стандарты |

## Вид изделия (`kinds[]`)

```json
{
  "id": "profile.rect",
  "group": "Профили",
  "variety": "Прямоугольные замкнутые",
  "title": "Профиль гнутый замкнутый сварной прямоугольный",
  "noun": "Профиль",
  "size_title": "Сечение h×b×t, мм",
  "appearance": "std.steel",
  "material": "Сталь",
  "build": [
    {"sketch": {"plane": "XY", "shapes": [
      {"rect": {"w": "b", "h": "h", "r": "R"}},
      {"rect": {"w": "b - 2*t", "h": "h - 2*t", "r": "R - t"}}
    ]}},
    {"extrude": {"distance": "L"}}
  ],
  "envelope": ["b", "h", "L"]
}
```

- `group` — папка окна «Библиотека». Можно указать существующую («Болты») или новую.
- `variety` — строка внутри папки; `title` — полное название; `noun` — для обозначения.
- `size_title` — подпись над размерами в окне.
- `envelope` — габарит по X, Y, Z (выражения); по нему проверяют тесты.

### Рецепт (`build`)

Шаги по порядку. Первый — эскиз. Первая операция создаёт тело; следующие по
умолчанию добавляются к нему (`join`).

| Шаг | Поля |
|---|---|
| `sketch` | `plane`: `XY`, `XZ` или `YZ`; `shapes`: фигуры |
| `extrude` | `distance`; `direction`: `normal` (по умолчанию), `reversed`, `symmetric` (distance — полная длина, поровну в обе стороны); `operation`: `new`, `join`, `cut` |
| `revolve` | `operation`; вращает последний эскиз на 360° вокруг его осевой |

Фигуры эскиза:

| Фигура | Поля |
|---|---|
| `rect` | `w`, `h` — размеры; `x`, `y` — центр (по умолчанию 0); `r` — радиус скругления углов (нет или 0 — острые) |
| `circle` | `d` — диаметр; `x`, `y` — центр |
| `hexagon` | `s` — размер под ключ; центр в начале координат, вершины на оси X |
| `polygon` | `points`: `[[x, y], …]`, не меньше трёх; `axis: true` — замыкающий отрезок (последняя → первая точка) становится осевой |
| `axis` | `ends`: `[[x, y], [x, y]]` — осевая для `revolve` |

Контуры одного эскиза, вложенные друг в друга, дают тело с отверстием
(профиль — наружный и внутренний `rect`).

### Выражения

Числа или строки: `"b/2 - R"`, `"2*t"`, `"max(R - t; 0)"`. Переменные —
столбцы таблицы с размерами и `L` (длина, если у стандарта есть длины).
Функции и правила — как в полях программы (`sin cos tan sqrt abs min max round`,
`pi`). Значения — миллиметры. Для **каждой** строки таблицы выражения размеров
(`w`, `h`, `d`, `s`, `distance`, `envelope`) должны давать больше нуля, иначе
пакет не загрузится.

## Стандарт (`standards[]`)

```json
{
  "id": "gost30245.rect",
  "title": "ГОСТ 30245-2003",
  "kind": "profile.rect",
  "note": "длина — отрезок любой длины",
  "family": "ГОСТ",
  "size": "{h}×{b}×{t}",
  "designation": "Профиль {h}×{b}×{t} ГОСТ 30245-2003, L={L}",
  "columns": [
    {"name": "h", "title": "Высота"},
    {"name": "b", "title": "Ширина"},
    {"name": "t", "title": "Толщина стенки"},
    {"name": "R", "title": "Наружный радиус закругления"},
    {"name": "m", "title": "Масса 1 м, кг", "length": false}
  ],
  "rows": [[50, 25, 2, 4, 2.15], [50, 25, 2.5, 5, 2.62]],
  "length": {"min": 1, "max": 13000, "default": 1000}
}
```

- `id` — постоянный ключ (на нём команды `library.*`); не меняйте после выпуска.
- `kind` — вид из этого пакета или из уже загруженного.
- `family` — фильтр окна: `ГОСТ`, `ISO`, `DIN`; без него — по началу `title`.
- `size` — как пишется размер; `{столбец}`. Размеры в таблице не повторяются.
- `designation` — обозначение: `{столбец}`, `{size}`, `{L}`, `{title}`, `{noun}`.
  Без него: «`{noun} {size}×{L} {title}`» (или без длины). Для ГОСТ точки в
  числах заменяются запятыми. **Обозначение — имя файла детали в сборке**:
  детали с разной длиной должны различаться обозначением (`L={L}`).
- `columns` — имя или `{name, title, length}`. Столбец с `length: false` —
  справочный (масса), переменной не становится. Имена столбцов-размеров —
  латиница или кириллица, не единицы (`m`, `mm`, `in`…), не `L`, не `d1`, `d2`…
- `rows` — по одному числу на столбец.
- Длина: `lengths: [10, 12, 16]` — только из списка; `length: {min, max, default}` —
  любая из диапазона; ни того, ни другого — у изделия нет длины.

## Проверка

`ParsePack` / `ReadPack` (`src/document/StandardPacks.h`) отвечают по-русски, что
и где не так. Тест `the shipped packs read and pass their checks` читает все
пакеты из `assets/library/`; тест в `tests/kernel/StandardPartsTests.cpp`
строит первую, середину и последнюю строку каждой таблицы и, если есть
столбец `m`, сверяет массу 1 м (сталь 7,85 г/см³) с таблицей в пределах 1 %.
