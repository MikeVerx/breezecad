## 1. Правила (автор)
- Отвечать по-русски. Офлайн, без телеметрии. Цвета — только токены темы.
- Маленькие шаги: правка → сборка → тест → коммит → push. Английские
  идентификаторы, UTF-8, LF. Без переписываний без доказательств.
- Видимый текст — только через `Tr("…")` / `Trf("… {}", x)`; в статических
  таблицах `N_("…")` + `Tr()` при показе; printf-форматы с переводом запрещены
  (`ImGui::Text("%s", Tr(..))`). Нижние модули (document/kernel/core) пишут
  по-русски целыми шаблонами `std::format("… {}", x)`, интерфейс переводит
  `Tr(std::string)` при показе. После новых строк: `python3 scripts/i18n/extract.py`.
- Windows-ловушки: `far`/`near` — макросы windows.h, не называть так переменные.
- Коммиты (автор попросил «для людей»): тело What/Why/Where/Tested, как в
  CONTRIBUTING.md (пример `git show c0bfa3d`); одна логическая часть на коммит.
- Репозиторий публичный (2026-10-12): минуты Actions бесплатны, macOS собирается на каждый push.
- Коммиты: в конце строки `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` и
  `Claude-Session: …` (см. системное напоминание сессии).

## 3. UI-тест (Xvfb)
`scripts/ui-test/ui.sh start [file]`, `clk X Y`, `key r`, `shot NAME [delay]`, `stop`;
`SHOTS=<scratchpad>/shots`. Экран 1600×1000, окно 1440×900 в (0,0).
Ctrl через xdotool не доходит — использовать Shift/клавиши/ленту.
Новая деталь: `clk 599 224` (кнопка «Деталь»; «Создать…» — `clk 445 224`); Начать эскиз `clk 52 115` → плоскость XY `clk 1060 507`.
В эскизе: `r` прямоугольник, `l` отрезок, `o` эквидистанта, Esc ×3–4 — выход.
Двойной щелчок в дереве: `mousemove x y; click --repeat 2 --delay 80 1`.
Тестовые детали: `tests/data/кронштейн.bzc` (плита+бобышка+отверстия+Плоскость1).
Сценарии: `scripts/ui-test/scenario-{box,hole,revolve,...}.sh`.

## 3а. Мониторинг (tools/monitor) — искать проблемы им, а не скриншотами
- Автор (Windows): `python tools/monitor/run.py --bin <папка с breezecad.exe>`, работать, закрыть
  программу → `tools/monitor/reports/<дата-время>.md` (+ `.json`, сырьё в папке того же имени).
- Сам (Linux, без человека): `python3 tools/monitor/run.py --scenario bracket|assembly`
  (Xvfb + `scripts/ui-test`; программный GL — кадры медленнее, чем на видеокарте; для цифр
  собирать `linux-release`, скрипт берёт release-сборку первой). Свой сценарий — путь к .sh.
- Ловит: вылет (что, последнее действие, стек; Windows — минидамп), зависание ≥ 2 с
  (`--hang-ms`; Linux — стек главного потока gdb'ом), кадры (p50/p95/p99, по действиям и
  стадиям `prof::Scope`), перестроения/загрузку деталей, ошибки/предупреждения со счётчиком,
  память. Программа пишет события только при `BZ_MONITOR=<файл>` (`core/Monitor.h`);
  действия всегда — строкой `DEBUG Action:` в логе. Новое действие пользователя без
  ActionRegistry/команды/Checkpoint — отметить `mon::Action(...)`; новая долгая стадия —
  `prof::Scope`.

## 7. Известные ограничения/баги (не забыть)
- Оболочка: замкнутая (без удалённых граней) строится смещением всего тела + вырезом — на сложных
  телах (кронштейн с отверстиями) OCCT может не построить; с удалённой гранью работает. Сообщение
  об ошибке всегда «толщина слишком большая?» — уточнить, если тестеры спросят.
- Библиотека: форма упрощена (без фасок головки, шлиц/шестигранник — простой вырез, подшипник одним
  телом с канавками, кольцо без «ушей», пружинная шайба плоская с прорезью). Открывается только
  с ленты открытого документа или через поиск команд (на главной странице кнопки нет).
  Вставка в сборку и AutoDrop — блок 3.
- Рабочая точка «Вершина» хранит ребро, оканчивающееся в ней; одиночная вершина без рёбер не берётся.
- Условная резьба: рисуется винтовой линией (не текстурой); масса/сечение/коллизии — по гладкому
  цилиндру; экспорт перестраивает копию детали с настоящей резьбой (синхронно, окно ждёт).
- Фоновое перестроение: результат по устаревшей ревизии показывается (геометрия), статусы — после
  следующего расчёта. Отменить идущую булеву операцию нельзя — дожидаемся и считаем заново.
- Сплайн/эллипс: точка на кривой и касательность есть (сплайн — только на его конце с отрезком/дугой/сплайном;
  эллипс — с отрезком где угодно). Обрезка эллипса/сплайна оставляет сплайн через точки старой кривой
  (дуги эллипса как сущности нет); эквидистанта — только одиночного сплайна/эллипса, результат — сплайн.
- Плоскость «под углом»: ребро не должно быть перпендикулярно исходной плоскости.
- Перевод: каталогов нет (автор переводит сам; шаблон `translations/template.json`).
- Допуск выбора рёбер поднят 4→7 px (Viewport.cpp, `SetPixelTolerance`) — проверить
  в бета-тесте (сопряжение, плоскость под углом, измерение), не мешает ли выбору граней.
