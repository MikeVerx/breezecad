## 1. Правила (автор)
- Отвечать по-русски. Офлайн, без телеметрии. Цвета — только токены темы.
- Маленькие шаги: правка → сборка → тест → коммит → push. Английские
  идентификаторы, UTF-8, LF. Без переписываний без доказательств.
- Видимый текст — только через `Tr("…")` / `Trf("… {}", x)`; в статических
  таблицах `N_("…")` + `Tr()` при показе; printf-форматы с переводом запрещены
  (`ImGui::Text("%s", Tr(..))`). Нижние модули (document/kernel/core) пишут
  по-русски целыми шаблонами `std::format("… {}", x)`, интерфейс переводит
  `Tr(std::string)` при показе. После новых строк: `python3 scripts/i18n/extract.py`.
- Windows-ловушки: `far`/`near` — макросы windows.h, не называть так переменные.
- Коммиты: в конце строки `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` и
  `Claude-Session: …` (см. системное напоминание сессии).

## 3. UI-тест (Xvfb)
`scripts/ui-test/ui.sh start [file]`, `clk X Y`, `key r`, `shot NAME [delay]`, `stop`;
`SHOTS=<scratchpad>/shots`. Экран 1600×1000, окно 1440×900 в (0,0).
Ctrl через xdotool не доходит — использовать Shift/клавиши/ленту.
Новая деталь: `clk 460 224`; Начать эскиз `clk 52 115` → плоскость XY `clk 1060 507`.
В эскизе: `r` прямоугольник, `l` отрезок, `o` эквидистанта, Esc ×3–4 — выход.
Двойной щелчок в дереве: `mousemove x y; click --repeat 2 --delay 80 1`.
Тестовые детали: scratchpad `кронштейн.bzc` (плита+бобышка+отверстия+Плоскость1).
Сценарии: `scripts/ui-test/scenario-{box,hole,revolve,...}.sh`.

## 4. Карта кода (куда смотреть)
- `src/sketch/` — ядро эскиза без UI: Sketch.h (Point/Line/Circle/Arc/**Spline**,
  Constraint), Solver/EquationSystem, Shapes, Trim (+Extend), Fillet, Offset,
  Move, Mirror, SplineGeometry. Тесты `tests/sketch/*`.
- `src/document/` — фичи и файл .bzc (JSON в zip). Новые поля читать
  `ReadMember` (отсутствие = ок → совместимость старых файлов).
- `src/kernel/Model.cpp` — перестроение (OCCT), `occt/*` — операции.
- `src/app/sketch/` — редактор эскиза: SketchEditor.h (enum SketchTool, DrawOptions),
  SketchEditor.cpp (таблица kTools, диспетчер инструментов ~стр. 320),
  SketchTools.cpp (Handle* инструментов), SketchToolPanel.cpp (левая панель),
  SketchOverlay/SketchPick (рисование/выбор).
- `src/app/features/` — панели операций; `DragArrow` (стрелки/дуги-манипуляторы).
- `src/app/AppActions.cpp` (команды+клавиши), `shell/Ribbon.cpp` (лента),
  `shell/Dialogs.cpp` (настройки), `core/I18n.*`, `app/Language.*`.
- Новый инструмент эскиза = enum в SketchEditor.h + строка kTools (+размер массива)
  + case в диспетчере + Handle*-функция + строка в AppActions tools[] + `r.Small` в Ribbon
  + (опц.) поле в SketchToolPanel + svg в assets/icons (стиль: 32×32, #1D4ED8 линия,
  #6F7884 вспомогательное, #E5484D акцент).

## 7. Известные ограничения/баги (не забыть)
- Сплайн: нет связей «точка на сплайне»/касательности, обрезка/удлинение его не видят.
- Плоскость «под углом»: ребро должно быть параллельно плоскости; вершины не выбираются.
- Перевод: каталогов нет (автор переводит сам; шаблон `translations/template.json`).
- Ребро выбирается только точным попаданием (допуск OCCT-селектора мал) — кандидат
  на улучшение (увеличить `PixelTolerance` селектора в Viewport).
