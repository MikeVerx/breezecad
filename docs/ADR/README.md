# Architecture Decision Records (ADR)

Здесь фиксируются ключевые архитектурные решения BreezeCAD.
Цель — чтобы через год было понятно, **почему** проект устроен так, а не иначе.

## Формат

Каждый ADR — файл `NNNN-краткое-название.md` со структурой:

- **Title** — краткое название решения
- **Status** — Proposed / Accepted / Deprecated / Superseded by ADR-XXXX
- **Date** — когда принято
- **Context** — какая проблема решается
- **Decision** — что именно решили
- **Consequences** — последствия (плюсы, минусы, что становится возможным)
- **Alternatives** — что рассматривали и почему отвергли
