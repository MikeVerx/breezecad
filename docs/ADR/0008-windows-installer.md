# ADR-0008: Установщик для Windows

- **Status:** Accepted
- **Date:** 2026-10-31

## Context

До 0.2.5 BreezeCAD для Windows был только архивом: распаковал и запустил.
Автору и тестерам надоело копить папки с версиями; Windows не знала
фирменных файлов (`.bzc`, `.bza`) — ни двойного щелчка, ни значков, ни
превью. Нужен стационарный вариант с установщиком, при этом портативная
версия без установки остаётся.

Требования автора (31.10.2026): красивое пошаговое окно в стиле программы;
язык — как в системе, кнопка **Language**; соглашение (MPL 2.0, «чистая
комната», отсутствие сбора данных, состав отчёта о сбое) с отказом через
предупреждение; папка с проверкой и язык программы; официальные модули;
ярлыки и типы файлов; во время установки — «Боль инженера» с картинками
сайта, логотип, версия, полоса и что сейчас происходит; финал с «Запустить
BreezeCAD». Обновление — поверх, без клонов. Превью детали/сборки с
логотипом на крупных и огромных значках, как у КОМПАС и Inventor. Макет:
холст Claude https://claude.ai/artifact/BaFHibWQpRABL9ZPDzMghS (одобрен; превью
в параметрах убрано — оно включено всегда).

## Decision

1. **Свой установщик**, не Inno Setup/NSIS/WiX: `installer/setup`, Win32 +
   Direct3D 11 + Dear ImGui. Выглядит как BreezeCAD и говорит на 16 языках
   (`installer/setup/strings/*.json`). Direct3D, а не OpenGL: на виртуальных
   машинах и старых драйверах OpenGL часто нет, а D3D11 с WARP есть всегда.
   Один `.exe` без DLL рядом (всё статически), ~4,5 МБ.
2. **Один установщик — два вида.** `BreezeCAD-Setup.exe` скачивает с GitHub
   (`setup-manifest.json` выпуска, затем файлы с проверкой SHA-256);
   `BreezeCAD-Setup-offline.exe` — тот же `.exe` с ZIP всего нужного в конце
   и меткой `BZSETUP1` + смещение. Онлайн-вариант с `main` смотрит в
   последний выпуск, с `next` — в `next-build` (`BZ_SETUP_CHANNEL`).
3. **Для пользователя, без администратора.** Папка по умолчанию
   `%LOCALAPPDATA%\Programs\BreezeCAD`, реестр — HKCU (Приложения, типы
   файлов, превью), ярлыки — пользовательские. Если выбрать папку вроде
   `Program Files`, права администратора просит только копирование (тот же
   `.exe` с `--unpack`), остальное — от имени человека.
4. **Обновление и удаление.** Установщик кладёт себя (без упакованных
   файлов) как `uninstall.exe`: это и «Удалить», и «Изменить» в «Приложениях».
   Обновление ставит поверх, удаляет файлы прежней версии, которых больше нет
   (`installed-files.txt`), занятые файлы (превью в Проводнике, запущенная
   программа) переименовывает в сторону. Если программа открыта — просит
   закрыть. Удаление по желанию оставляет настройки, модули и языки.
5. **Где живут модули и языки.** Установленная копия (рядом
   `installed.json`) держит их в профиле (`%APPDATA%\BreezeCAD\modules`,
   `…\lang`) — они переживают обновления. Портативная — в папках `module` и
   `language` рядом с программой. Пакеты `.bzmod`, найденные в папке модулей,
   программа ставит при запуске (так их передаёт установщик и так их можно
   положить руками в портативную версию).
6. **Языки.** Окна установщика — на всех языках сразу (сам `.exe`). Программа
   везёт русский и английский; пакет выбранного языка (`lang-<code>.zip`:
   перевод и шрифт) онлайн-установщик докачивает, офлайн везёт все.
   Портативная — только русский и английский, остальные кладутся в
   `language` вручную.
7. **Превью.** При сохранении документа, который на экране, в файл ложится
   `preview.png` — изометрия на прозрачном фоне 512×512 (два снимка на чёрном и
   белом дают прозрачность). `bz_thumbs.dll` (`installer/thumbnails`) — обработчик
   миниатюр Проводника: достаёт картинку, на значках от 72 px рисует в углу
   знак BreezeCAD. Файл без картинки — обычный значок типа
   (`installer/icons/*.ico`, рисует `scripts/installer/make-icons.py`).
8. **Проверка в CI.** Офлайн-установщик ставится на настоящей Windows
   (`--test-install`), проверяются файлы, реестр, модули, затем тихое
   удаление; снимки всех страниц (`BZ_SETUP_SHOTS`) — артефакт `setup-screens`.

## Consequences

- Linux и macOS пока остаются с архивами; их установщики — отдельным шагом.
- Соглашение — на русском и английском; на других языках установщик
  показывает английский текст с пометкой.
- Языковые пакеты программы появятся вместе с переводами (следующий пункт
  0.2.5); манифест и установщик к ним уже готовы.
