# UI Issues — очередь на исправление

**Создано:** 2026-09-23
**Статус:** открыто

## Ribbon — размеры и компоновка

- [ ] **Адаптивный размер иконок в big-кнопках работает неравномерно.**
      У «Лофт», «Отверстие», «Резьба» — иконки крупные. У «Пересечение»,
      «Оболочка» — мелкие. Причина: адаптив не учитывает фактическую высоту
      текста, только ширину.
- [ ] **Малые кнопки в «Ограничениях» — слишком мелкие после 24 px.**
      Иконки ограничений почти не читаются.
- [ ] **Группа «Ограничения» тянется/сжимается относительно других.**
      Нужно жёсткое выравнивание всех групп по высоте через member-переменную
      + push/pop cursor Y.

## Локализация

- [ ] **`tool.project.loop` не переведён** — показывается как есть.
      Нужно добавить в Localization.cpp: `{ "tool.project.loop", { "Project Edges", "Проецирование рёбер" } }`.

## Формат (Эскиз)

- [ ] **Подпись «Основная» не по центру кнопки.** Причина: framePadding
      кнопки не компенсирует разницу между «Основная» / «Вспомог.» / «Осевая».

## Сборка

- [ ] **Кнопки «Спецификация» / «Библиотека» — мелкие по сравнению
      с остальными группами.** Причина: те же малые кнопки 24 px.

## Вид

- [ ] **«Новое окно» — мелкое.** То же.
- [ ] **«Пересечение» (3D-модель) — крупнее.** Хотя по чеклисту —
      нужно проверить: у нас есть Intersect или нет?

## Открытые вопросы

- **Пересечение и Оболочка** — по словам MikeVerx, их не должно было быть
  в чек-листе. Проверить UI_LAYOUT.md (секция 4.1, группа «Изменить»).
  Если не должно быть — убрать из ribbon.

## Стратегия следующей сессии

Скорее всего, нужно:
1. **Отказаться от адаптивного iconSize** — сделать единый для всех
   big-кнопок (например, 32).
2. **Малые кнопки — 32 px** (не 24), но с меньшим spacing.
3. **Жёсткое выравнивание всех групп** до 74 px через Dummy в `RibbonGroupEnd`,
   но с правильной реализацией (member-переменная уже есть).
4. **Проверить локализацию** `tool.project.loop` — добавить в словарь.

Скорее всего, будет полезно **пересмотреть всю группу `RibbonGroup*`** —
сделать её проще и предсказуемее.
