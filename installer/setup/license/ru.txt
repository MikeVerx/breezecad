# 2. Сторонние компоненты
В программу входят компоненты других авторов, каждый под своей лицензией: Open CASCADE Technology (LGPL 2.1 с исключением), Dear ImGui, GLFW, nlohmann/json, miniz, LunaSVG, portable-file-dialogs (MIT/zlib), stb (общественное достояние), шрифты IBM Plex (SIL OFL 1.1). Тексты их лицензий лежат в папке программы.

Названия других программ упоминаются только для описания привычных пользователю схем управления; товарные знаки принадлежат их владельцам.

# 4. Ваши данные
Программа работает офлайн и не собирает, не хранит и никуда не отправляет сведения о вас, ваши детали, сборки и статистику использования. Рекламы и аналитики нет.

Отчёт о сбое формируется на вашем устройстве и отправляется разработчикам, только если вы сами так решите. В отчёт входят исключительно журнал работы программы и конфигурация устройства: операционная система, процессор, видеокарта, объём памяти, версии драйверов. Файлы моделей в отчёт не входят.

В сеть обращается только онлайн-установщик и только для скачивания выбранных вами компонентов с GitHub.
