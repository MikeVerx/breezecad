# 4. Your data

A crash report is created on your device and sent to the developers only if you decide so. It contains only the program log and the device configuration: operating system, processor, graphics card, memory size, driver versions. Model files are never included.

Only the online installer goes online, and only to download the components you chose from GitHub.
