# Языки BreezeCAD / BreezeCAD languages

## Как поставить язык

1. Скачайте файл языка (`.json`) отсюда или от автора перевода.
2. В BreezeCAD: **Настройки → Интерфейс → Папка языков** — откроется папка.
3. Положите файл туда, закройте и снова откройте окно настроек — язык появится в списке.

Программа сама ничего не скачивает и не выходит в интернет.

## Как перевести

Исходный язык программы — русский: русский текст строки и есть её ключ.

1. Скопируйте `template.json` в файл с кодом языка, например `de.json`.
2. Впишите `code` (`"de"`) и `name` — название языка на нём самом (`"Deutsch"`).
3. Заполните переводы. Пустая строка — останется русский текст, так что перевод
   можно делать по частям.
4. `{}` и `{:.1f}` — места для чисел и имён: сохраните их в переводе в том же
   количестве. Если перевод сломает их, программа покажет русский текст, а не упадёт.
5. Строки с `\n` — перенос строки (например, подписи кнопок ленты в две строки).

Новые строки после обновления программы:

    python3 scripts/i18n/extract.py --update translations/de.json

Скрипт добавит новые строки пустыми и уберёт те, что больше не используются.

## Installing a language

Put the `.json` file into **Settings → Interface → Languages folder** and reopen
the settings window. To translate, copy `template.json`, set `code` and `name`,
fill in the strings (an empty one stays Russian), keep `{}` placeholders.
